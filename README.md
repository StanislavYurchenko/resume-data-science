# Data Science Engineer Resume | Stanislav Yurchenko

This repository contains the source code for my **Data Science Engineer** resume. 

As a Senior Software Engineer with a strong background in frontend architecture and industrial automation, I am currently expanding my expertise into Data Science and Machine Learning. This resume is specifically tailored to highlight my experience with data-driven logic, statistical analysis, and ML technologies.

*Note: This project was created as a practical assignment for the **Python Data Science & Machine Learning** course at GoIT Academy.*

## 🛠 Technologies & Tools
The resume is built using pure web technologies to ensure lightweight performance and easy customization:
*   **HTML5** - Semantic structure.
*   **CSS3** - Custom styling with a clean, modern design.
*   **Print CSS (`@media print`)** - Optimized for flawless PDF generation directly from the browser.

## 🚀 Features
*   **Dual Profile Strategy:** Separates my Data Science journey from my primary Frontend Engineering portfolio.
*   **ATS-Friendly:** Structured with clear headings and keywords (Python, Pandas, ML, SQL) to pass Applicant Tracking Systems.
*   **PDF-Ready:** The layout automatically adjusts margins, hides UI buttons, and reformats columns when printing to PDF.
